Module 2｜瓣膜疾病與主動脈瓣手術

從「瓣膜是什麼」一路走到「這個病人該換哪一顆瓣膜」。這是全課程中臨床決策密度最高的一段。

Lesson 2-1｜瓣膜就是單向閥:四種壞法

TL;DR｜瓣膜的唯一功能是讓液體或氣體單向通過。心臟以外,靜脈、淋巴管、迴盲瓣、食道下端、聲帶都在做同一件事。心臟瓣膜的失能可歸成四大病因。

Hook

2% 的人天生是雙葉主動脈瓣(bicuspid aortic valve),但他們未必會生病——只是因為開口較小、血流造成的退化較早,常在 40、50 歲就出問題,而不是一般退化性瓣膜的 70、80 歲。

Framework

把瓣膜理解成調節單向流動的閥門,身體多處都有:

  • 靜脈瓣:多分布於下半身,人是直立動物,沒有它血液就積在下肢(靜脈曲張即瓣膜損壞)
  • 淋巴管瓣膜:引導淋巴回到 thoracic duct
  • Ileocecal valve:防止大腸內容物與氣體逆流回小腸
  • 食道胃交界:實為括約肌,功能類似瓣膜
  • 聲帶:調節發聲,並防止食物進入氣道

Structured Detail｜瓣膜 dysfunction 的四大病因

類型形態特徵好發常見結果
退化性(degenerative)仍是三葉,但葉片全面增厚老年人,70–80 歲以上Aortic stenosis

Visual｜一張 2×2 的瓣膜照片牆:左上厚實三葉(退化)、右上兩葉帶 raphe、左下有破洞(感染)、右下鬆垮下垂(自體免疫)。四張圖各拉一條箭頭指向下方兩個結局框:「Stenosis」與「Regurgitation」。

⭐ 考試重點｜「bicuspid aortic valve 佔約 2% 人口、多數不發病、但退化較早」是高頻考點;此外 bicuspid 與升主動脈病變同源,見 Module 4 的主動脈剝離危險因子。

Recall Check｜一位 46 歲男性因主動脈瓣狹窄轉診。以年齡推論,你最懷疑的病因是哪一種?你會在超音波上找什麼特徵來支持這個推論?

Lesson 2-2｜Stenosis vs Regurgitation:壓力超載 vs 容積超載

TL;DR｜同樣走向心衰竭,但路徑完全不同。狹窄 → pressure overload → LVH;逆流 → volume overload → LV 擴大。兩者的代償機轉不同,時間尺度也不同。

Hook

如果正常血壓是 120,而狹窄造成的壓差是 80,那麼左心室內的壓力就是 200。心臟不是被外力壓迫,而是被自己逼出來的高壓所傷。

Framework

退化的兩個結局,對應兩種超載:

  • 狹窄:上游是左心室 → 必須用力 → 壓力差 → Pressure overload → 心肌肥厚(hypertrophy)→ 經過很長時間 → heart failure
  • 逆流:血液回流入左心室 → 容積過多 → Volume overload → LV chamber dilate(超音波上 LVEDD 變大)→ 透過 Frank-Starling law 仍能維持較佳 stroke volume → 代償終究失效 → heart failure

講者特別強調:LVH 走到心衰竭究竟要多久其實無法預測——可能 20 年、30 年,也可能終其一生不發作。

Aortic StenosisAortic Regurgitation
負荷型態Pressure overloadVolume overload
心室變化心肌肥厚(hypertrophy)心室腔擴大,LVEDD ↑

Visual｜左右並排兩顆左心室剖面。左邊室壁畫得很厚、腔室很小,標「200 mmHg」;右邊室壁正常厚度但腔室明顯撐大,標「LVEDD ↑」。兩者最下方箭頭匯流到同一個框:Heart Failure。

⭐ 考試重點｜「AS = pressure overload = LVH」「AR = volume overload = LV dilatation + Frank-Starling 代償」是這一段的骨幹題。

Recall Check｜超音波報告顯示 LVEDD 明顯增大但室壁厚度正常。以本課架構判斷,這位病人的瓣膜問題比較可能是狹窄還是逆流?他目前是靠什麼機轉維持心輸出量?

Lesson 2-3｜AS 的三大症狀與它們的時鐘

TL;DR｜Aortic stenosis 的 cardinal symptoms 有固定順序:chest pain → syncope → heart failure。不治療的話,對應的「一半病人出事」時間分別是 5 年、3 年、2 年。

Hook

症狀一旦出現,時鐘就開始倒數:chest pain 五年、syncope 三年、heart failure 兩年——各有一半病人會出大事,可能是休克、垮掉,甚至死亡。

Framework

三大症狀不是隨機出現,而是同一個病生理的三個階段:

  1. Chest pain:左心室壓力大 → 做工變多 → 需氧量增加 → 供需失衡。心電圖上會有變化。
  2. Syncope:誘因不固定——可能是感冒、疲勞,也可能只是晚餐後看電視或爬樓梯走路時發生。是心衰竭的前哨。
  3. Heart failure:最終結局。

Structured Detail｜Cardinal symptoms 與預後

症狀機轉不治療:一半病人出事的時間
Chest painLV 壓力高 → 心肌需氧量增加5 年
Syncope心輸出量在需求增加時不足3 年
Heart failure代償失效2 年

Visual｜一條由左至右的時間軸,三個節點依序標 Chest pain、Syncope、Heart failure。每個節點下方掛一個沙漏,沙漏上寫 5y、3y、2y,沙漏一個比一個小。

⭐ 考試重點｜「5 / 3 / 2 年」這組數字幾乎是外科教科書必考;順序不可顛倒。

Recall Check｜一位已知中度 AS 的病人,最近在家看電視時暈厥一次。依本課的時鐘,他目前落在哪一階段?你會建議「持續追蹤」還是「盡快尋求手術評估」?為什麼?

Lesson 2-4｜「喘」的順序,以及右心衰竭的臉

TL;DR｜瓣膜性心臟病的喘有固定進程:DOE → PND → orthopnea。壓力一路往後傳到肺、再到右心,最後表現成腳腫、腹水、胃口差、黃疸。

Hook

病人抱怨「腳腫、吃不下、皮膚變黃」時,消化科的鑑別診斷之外,別忘了這可能是一顆瓣膜壞掉之後,壓力一路傳到右心的終點站。

Framework

把它想成一條由前往後塞車的路線:

瓣膜逆流 → LV 舒張壓 ↑ → LA 壓 ↑ → 肺靜脈與肺微血管壓 ↑ → 喘 → 肺動脈高壓 → 右心 dilate → TR → RA 壓 ↑ → 全身靜脈鬱血

關鍵補充:右心壁比左心薄,對高壓的適應能力較差,所以一旦肺動脈高壓持續,右心很快就擴大。

Structured Detail

階段臨床表現
早期Dyspnea on exertion(DOE):活動時喘
中期Paroxysmal nocturnal dyspnea(PND):夜間睡覺喘醒
晚期Orthopnea:端坐呼吸
Forward flow 不足虛弱無力
LA 壓上升後Arrhythmia、心悸(palpitation)
右心衰竭下肢水腫、ascites、visceral congestion、胃口不好、黃疸

Visual｜一條由左心室出發、往後逆行的箭頭鏈:LV → LA → 肺靜脈 → 肺微血管 → 肺動脈 → RV → RA → 全身靜脈。在肺微血管處掛「喘」的標籤,在最末端掛「腳腫 / 腹水 / 黃疸」。

⭐ 考試重點｜講者在課末思考題明確要求:「喘」背後的生理原因與右心衰竭的症狀各是什麼。這兩題請完整背下來。

Recall Check｜病人說他半年前只有爬樓梯會喘,最近改成「夜裡會被喘醒」。用本課的三階段架構說明疾病進展到哪裡,並解釋為什麼平躺會加重症狀。

Lesson 2-5｜AVR:一台手術的七個動作

TL;DR｜主動脈瓣置換的骨幹是:建立體外循環 → 阻斷主動脈 → 灌注心臟麻痺液 → 切開主動脈 → 切除瓣膜 → 環圈縫線置入新瓣膜 → 關閉切口、脫離體外循環。

Hook

手術檯上,主動脈被夾子阻斷之後,把主動脈切開的那一刻,主動脈瓣就直接呈現在術者眼前——講者示範的那一顆,是一個真正的雙葉瓣(true bicuspid aortic valve)。

Framework

整台手術的邏輯是:先讓心臟安全停下來 → 在無血的視野裡換掉瓣膜 → 再把心臟接回循環。

Structured Detail｜步驟

#動作要點
1建立體外循環兩根靜脈導管、一根動脈導管
2Aortic cross-clamp夾子夾在主動脈上,阻斷血流
3灌注 cardioplegia使心臟停止跳動
4切開主動脈顯露主動脈瓣
5切除病變瓣膜—
6環圈縫線沿瓣膜環圈以帶 pledget 的 Ticron 線縫一圈,線頭留在外面
7置入並固定新瓣膜順著縫線把瓣膜滑到定位後打結;示範所用為牛心包生物瓣
8關閉主動脈切口逐步脫離體外循環,完成手術

Visual｜六格連環圖:①夾住的主動脈與插管 ②切開後露出的雙葉瓣 ③空的瓣膜環圈 ④環圈一圈的 pledget 縫線(線頭朝上散開)⑤瓣膜順著線滑落定位 ⑥打結完成的生物瓣就位。

⭐ 考試重點｜pledget + Ticron 環圈縫合、以及「先縫線再滑入瓣膜」的順序,是見習時最常被問的操作邏輯。

Recall Check｜為什麼縫線要先整圈穿好、線頭留在心臟外面,而不是把瓣膜先放到定位再一針一針縫?從視野與精準度的角度說明。

Lesson 2-6｜生物瓣 vs 機械瓣:九個真實情境

TL;DR｜年齡是起點不是終點。65 歲是常用分水嶺,但鈣化代謝速度、懷孕計畫、抗凝血劑可近性、共病、生活型態,都可能推翻教科書答案——很多情況的正解是 shared decision making。

Hook

一位 40 歲印尼籍移工緊急需要換瓣膜,無法溝通、聯絡不到家屬。講者的選擇是生物瓣——理由不是年齡,而是他日後可能回到不易取得 warfarin 與 INR 監測的環境。

Framework

兩類材質的核心取捨:

  • 機械瓣(現多為雙葉 bileaflet,titanium 外覆石墨/碳鍍層抗凝血):耐用,但終身服用抗凝血劑
  • 生物瓣(豬瓣膜、牛心包膜):不需終身抗凝(約 3–6 個月),但會退化——現代抗鈣化技術下大約 15–20 年,且沒有永遠不用再換的瓣膜

影響生物瓣壽命的因素:抗鈣化技術世代、瓣膜口徑大小(孔洞大 → 壓差小 → shear force 小)、以及病人體質——年輕人、青少年、懷孕、洗腎病人鈣代謝旺盛,生物瓣壞得更快;hyperlipidemia、糖尿病也是負面因子。

⭐ 考試重點｜「>65 歲用生物瓣、<65 歲用機械瓣」是基準答案,但情境題的得分關鍵在能否指出推翻基準的那個因子。另記:生物瓣抗凝約 3–6 個月(等待縫合座 pseudo-endothelialization),機械瓣 lifelong。

Lesson 2-7｜Warfarin 與 INR:兩端都是懸崖

TL;DR｜Warfarin 是 vitamin K antagonist,影響 factor II、VII、IX、X,其中 VII 屬 extrinsic pathway → 所以監測 PT/INR。吃太多會出血,吃太少瓣膜會血栓,中間那段就是 therapeutic range。

Hook

換了機械瓣之後,目前唯一被證實能有效預防瓣膜血栓的口服藥只有 warfarin。Aspirin 只能當輔助,NOAC 目前尚未被證實足夠,力道不夠會有血栓風險。

Framework

作用機轉:warfarin 作用於肝臟,與 vitamin K 競爭,降低 coagulation factor II、VII、IX、X 的生成。

  • Factor VII → Extrinsic pathway 的關鍵 → 所以我們測 PT
  • Factor IX → intrinsic 的一小部分,相對 minor
  • Factor X → common pathway 起點(新型 Factor Xa inhibitor 即作用於此)
  • Factor II(prothrombin)→ 位於下游

為什麼要 INR 而不是 PT 秒數? 同一份檢體,不同醫院因試劑、溫度、實驗室條件差異,可能一家測 12 秒、另一家 12.5 秒。International Normalized Ratio 就是用標準試劑校正後的倍數,讓不同機構的數字可以互相比較。

Structured Detail｜Therapeutic range

情境INR 目標
Mechanical valve(標準教科書)2–3,或 2.5–3.5
Atrial fibrillation相對較低
DVT相對較低

Visual｜一條橫向的 INR 數線。左端畫血栓塞住的瓣膜(吃太少),右端畫出血(吃太多),中間一段塗綠色標「therapeutic range」。綠段可左右平移,旁邊註明可平移的理由:瓣膜種類、年齡、出血體質。

⭐ 考試重點｜講者思考題直接問:warfarin 要測什麼指標(三個英文字)、太短會怎樣、太長會怎樣、目標值如何選取,以及生物瓣 vs 機械瓣各需服用多久。

Recall Check｜為什麼 warfarin 監測用 PT 而不是 aPTT?從它抑制的四個凝血因子中,指出決定這個選擇的那一個,並說明它位於哪一條 pathway。

Lesson 2-8｜TAVI:不開胸的瓣膜置換

TL;DR｜經導管主動脈瓣置換(TAVI)把生物瓣裝在支架上,由股動脈逆行送到瓣膜環圈釋放。順利的話一兩個小時完成,但目前主要限用於狹窄,且有價格與適應症限制。

Hook

影像上你會看到導管沿著主動脈弓進入升主動脈,打顯影劑後定位瓣環與兩側冠狀動脈開口(術前已由 CT 標定),接著 sheath 緩緩後退,瓣膜像喇叭花一樣張開——釋放完成後再打一次顯影劑確認,常見僅輕微逆流。

Framework

結構上,TAVI 瓣膜就是「支架 + 心包膜生物瓣」的組合:外圈是可擴張支架,內部仍是牛心包膜做的瓣葉。它的存在也回答了 Lesson 2-6 的一個延伸問題——生物瓣退化後,未來有機會用 TAVI 再做一次(valve-in-valve 的思路)。

Structured Detail｜目前的限制

限制說明
價格昂貴
適應病灶主要用於 aortic stenosis;aortic regurgitation 因卡不住,目前尚不適用
健保適應症有一定規範
感染性心內膜炎不會採用此途徑
年輕病人durability 與 long-term outcome 目前未知

手術時間:順利時約 1–2 小時。

Visual｜四格影像序列:①導管沿主動脈弓下行 ②顯影劑標出 sinus of Valsalva 與冠狀動脈開口 ③sheath 後退、瓣膜半張如喇叭花 ④完全釋放,支架金屬網就位。

⭐ 考試重點｜「TAVI 目前主要用於 AS 而非 AR」與「年輕病人 durability 未知」是最常被拿來設計選擇題的兩個限制。

Recall Check｜術前 CT 為什麼要標定兩側冠狀動脈開口的位置?如果沒有做這件事,釋放瓣膜時可能發生什麼併發症?

Lesson 2-9｜PPM:換了瓣膜,病人還是喘

TL;DR｜Patient-prosthesis mismatch = 瓣膜有效開口對這個人的體型太小。以 EOAi = EOA / BSA 判定:>0.85 可接受,<0.85 不足,<0.65 嚴重不足。

Hook

正常人的主動脈出口面積大約 4 cm²,但你能放進去的人工瓣膜大約只有 2 點幾 cm²——19 號可能只剩 1 點幾。瓣膜本身沒壞,病人卻運動就喘。

Framework

把它想成一座天平:一邊是瓣膜的有效開口面積(EOA),另一邊是病人的體表面積(BSA)。兩邊不成比例,壓差就會偏高,連帶產生一連串後果。

Structured Detail

PPM 造成的後果:

  • 壓差大 → LVH 無法好好 regression
  • 冠狀動脈血流不順 → coronary flow reserve 不足 → 運動耐受性差
  • LV 無法好好 reverse remodeling → 合併的 mitral regurgitation 改善較慢
  • Functional class 變差、運動仍喘、cardiac event 增加
  • 瓣膜較小 → 較易 structural valve dysfunction(生物瓣提早壞)

判定標準:

EOAi(EOA / BSA)判讀
> 0.85可接受
< 0.85不足
< 0.65嚴重不足

如何預防與矯正:

時機做法
術前由身高體重推算 BSA;由 CT 量測 aortic annulus;查廠牌對照表(例如同為 21 號,不同型號的 EOA 可能差很多)並事先與病人說明
術中選擇選新世代、支架較薄、孔洞較大的瓣膜;或考慮 TAVI(結構更薄)
術中擴大Root enlargement

Root enlargement(Manouguian)怎麼做:從主動脈切口順著往下剪,經過 aortic annulus 剪進後方的 mitral valve,形成缺口,再用心包膜補一塊大補片。每多補約 1 公分寬度,換算成瓣膜口徑約除以 3,大致可多 3–4 個號數。另有一種切口位置略偏的做法稱為 Nicks。

Visual｜左半張:一個天平,左盤放小小的瓣膜開口、右盤放一個大體型的人,天平嚴重傾斜。右半張:主動脈切口向下延伸經 annulus 進入 mitral valve,補上一塊寬約 1 cm 的心包補片,旁邊標「≈ +3–4 號」。

⭐ 考試重點｜EOAi 的 0.85 / 0.65 兩個切點,以及「術前如何預先發現 PPM 風險」(BSA + CT annulus + 廠牌對照表)是本課的核心考題。

Recall Check｜一位 BSA 較大的男性,依 CT 只能放 21 號瓣膜,查表後 EOAi 估算約 0.7。列出你在術前與術中各能採取的一個具體對策,並說明 root enlargement 大約能換得幾個號數。
