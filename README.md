# 心臟血管外科微課程

由臺大醫學院心臟血管外科系列課程逐字稿整理而成的微學習教材。
9 個模組、53 課,每課約 3 分鐘,結尾均附主動回想題。

## 部署到 GitHub Pages

1. 把本資料夾內所有檔案(含 `.nojekyll`)放到 repo 根目錄,或放進 `docs/`
2. Repo → Settings → Pages → Source 選 `main` 分支 + `/ (root)` 或 `/docs`
3. 網址即為 `https://<你的帳號>.github.io/<repo 名稱>/`

`.nojekyll` 是必要的,可避免 Jekyll 處理靜態檔案。

## 檔案結構

```
index.html    目錄頁(入口)
style.css     共用樣式
m1.html ~ m9.html   九個模組
insights.html Insight Cards
```

純靜態 HTML,無框架、無建置步驟,雙擊 index.html 即可本機預覽。

## 注意

語音辨識的術語錯誤已還原為標準醫學名詞;所有數值、比例與研究結果均依講者原述保留,未經增補。本教材僅供學習使用。
