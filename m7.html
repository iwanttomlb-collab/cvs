Module 7｜TAPVR 與單心室循環

兩個主題共用同一個核心問題:當血液走錯路,或只剩一個幫浦時,循環要怎麼重新設計?

Lesson 7-1｜TAPVR:肺靜脈接到了不該接的地方

TL;DR｜四條肺靜脈本該回到左心房,卻接到別處。依回流位置分四型:supracardiac、intracardiac、infracardiac、mixed。

Hook

當所有肺靜脈血都回到右邊,左心房與左心室幾乎沒有血液進入——systemic circulation 形同停擺。這樣的小朋友能活著送到手術房,一定是因為心臟裡還有某個交通。

Framework

發育初期肺靜脈沒有接上左心房,轉而連到別的靜脈系統。接到哪裡,就決定了分型與預後。

Structured Detail｜四型 TAPVR

型別回流路徑
Supracardiac(較常見)四條肺靜脈匯成 confluence → bridging / vertical vein → innominate vein 或 SVC → 右心房 → 右心室 → 肺循環
IntracardiacConfluence 直接連到 coronary sinus(coronary sinus 本就注入心臟內)→ 右心房
Infracardiac連到心臟以下構造:多為 hepatic vein 或 IVC,少數連到 portal vein
Mixed(少見)兩側不同型,例如右側 supracardiac、左側 infracardiac 或 intracardiac

Visual｜一張中央為心臟的示意圖,四條肺靜脈匯成一個 confluence,再由 confluence 拉出四條不同顏色的引流路徑:向上到 innominate vein/SVC、直接進入 coronary sinus、向下經 hepatic vein 到 IVC、以及左右不同方向的混合型。

⭐ 考試重點｜四型的名稱與各自的回流目標血管;supracardiac 的 vertical/bridging vein 與 intracardiac 的 coronary sinus 是最常被指認的構造。

Recall Check｜若肺靜脈血全部回到右心系統,為什麼左心室仍可能有血液?請指出可能提供交通的兩個構造。

Lesson 7-2｜先天性心臟外科唯一的真急症

TL;DR｜嚴格說來,先天性心臟手術中絕對需要立即緊急處理的只有 TAPVR。急迫程度取決於左右之間的 mixing 夠不夠——只有小 PFO 或只有 PDA 的病人可能要邊 CPR 邊送手術房。

Hook

講者的原話很直接:「先天性心臟病手術領域裡,最絕對需要馬上緊急處理的,嚴格說起來只有這一個疾病。」

Framework

判斷急迫性只看一件事:肺循環與體循環之間有沒有足夠的血液混合。

因為血液全回到右邊,右側壓力必然大於左側,所以這些小朋友的 PFO 通常會一直開放(正常情況下左壓大於右壓後 PFO 會關閉)。但光靠 PFO 或光靠 PDA,交通量並不夠。

Structured Detail｜依 mixing 分層

合併的交通血氧與灌流急迫性
僅小 PFO,或僅 PDASaturation 與 tissue perfusion 都非常差極端者需邊 CPR 邊送手術房
單一 PFO(勉強維持)血氧與灌流仍很差仍需盡快緊急手術
合併較大的 ASDBlood mixture 較好(secundum ASD 通常大於 PFO)可稍微拖延後再送手術房
合併 VSD交通更佳仍會盡快手術,但相對沒那麼緊急

Visual｜一條由左至右的急迫性刻度尺,最左端標「邊 CPR 邊送刀房」、最右端標「可安排時間」。刻度上依序放置四個標籤:小 PFO / 單獨 PDA → 單一 PFO → 較大 ASD → 合併 VSD。

⭐ 考試重點｜「TAPVR 是先天性心臟外科唯一的真正急症」與「急迫性由 mixing 程度決定」——這是最容易被單獨命題的觀念。

Recall Check｜為什麼 TAPVR 的病嬰,PFO 反而不會像正常新生兒那樣自行關閉?請從左右心房的壓力關係說明。

Lesson 7-3｜TAPVR 手術:方向決定難度

TL;DR｜手術概念很單純——把 confluence 打開接回左心房、綁掉 vertical vein、關掉 ASD/PDA。難度差別在切口方向合不合:supracardiac 順、infracardiac 呈 90 度、再狹窄機率較高。

Hook

這個手術的 surgical mortality 已降至約 5%——講者特別點出,這比成人 type A aortic dissection 還要低。

Framework

不論哪一型,概念都是:把 confluence 剪開 → 接到左心房 → 綁掉異常引流 → 關閉 ASD/VSD/PDA 等原本賴以維生的交通。

Structured Detail｜三型的手術差異

型別做法幾何關係
Supracardiac綁掉 bridging vein,剪開 confluence,與打開的左心房吻合Confluence 的位置、大小與走向與 LA 較接近、方向一致 → 解剖上較不衝突
Infracardiac將下方截斷後打開 confluence,並調整 LA 切口以配合Confluence 與 bridging vein 走得很長且縱走,與 LA 的橫向寬度呈 90 度角,位置也較遠 → 再狹窄機率相對較高
Intracardiac可完全由心臟內部完成:打開右心房,自 foramen ovale 把 septum 挖開,再從 coronary sinus 剪通形成 tunnel,以補片整個蓋住,使肺靜脈血直接導入左心房因肺靜脈血與心臟自身靜脈回流已混合、無法分開,故一併導向左側

Outcome:

  • Surgical mortality 近期已降至約 5%
  • 越單純者(supracardiac、confluence 大)outcome 越好;複雜型或 mixed type 合併 confluence 狹窄或偏小者較差
  • 最在意的併發症是術後再狹窄,尤其在與 LA 的吻合口:發生率約 5–15%,多出現在術後 6 個月至 1 年內。高風險者可在 ICU 觀察後,約兩三個月安排斷層掃描追蹤
  • 再狹窄成因:本身構造較小 + 縫合接口處的組織增生 / intimal hyperplasia
  • 需再次手術者的 survival 明顯較不需再手術者差很多

預防再狹窄:sutureless anastomosis。既然增生組織長在縫線上,那就不要碰肺靜脈剪開的邊緣——把 LA 縫到更外側的 pericardium 上。肺靜脈本就位於心包膜後方,要顯露 PV confluence 必須打開心包膜,因此該邊緣即為心臟後方的心包膜:組織較堅韌,且離肺靜脈血管組織較遠,不易再狹窄。另一種做法是打開 PV 後,直接把外側心包膜剪開整個蓋起來。

Visual｜左半:兩張幾何對照。supracardiac 的 confluence 與 LA 切口平行(兩條平行線,好接);infracardiac 的 confluence 縱走、與 LA 橫向切口呈 T 字交叉(標「90°」)。右半:sutureless 示意——縫線不落在剪開的 PV 邊緣,而是落在更外側的心包膜上。

⭐ 考試重點｜再狹窄率 5–15%、好發於術後 6 個月至 1 年、成因(構造小 + intimal hyperplasia)、以及 sutureless anastomosis 的原理。

Recall Check｜為什麼 sutureless anastomosis 能降低再狹窄?請說明它「避開了什麼」以及「改縫在什麼組織上」,並解釋該組織為何較適合。

Lesson 7-4｜單心室循環:為什麼不能就這樣過一生

TL;DR｜只剩一個心室時,它同時承擔肺循環與體循環,負擔是正常的兩倍,且缺氧血與充氧血混合、效率極差。不處理的話,這些小朋友都活不久。

Hook

正常人的 Hb 約 15 以下;長期低血氧的單心室小朋友,身體拼命製造紅血球,Hb 可以高達 25、27 甚至 30——代價是 hyperviscosity syndrome 與血栓。

Framework

典型的單心室疾病:

  • Tricuspid atresia:右邊發育不全,幾乎沒有功能性 RV,只剩 LV
  • HLHS(hypoplastic left heart syndrome):左邊構造(mitral atresia、aortic stenosis、coarctation 等)未發育完全,只剩 RV 有功能

正常人是雙心房雙心室動物,pulmonary circulation 與 systemic circulation 各有各的幫浦。單心室時,一個幫浦要撐兩套循環。

Structured Detail｜不處理的四大問題

問題機轉與後果
負擔加倍正常時左右心各承擔 1;單心室同時負擔肺與體循環 → 約兩倍 → 心臟撐不久
效率極差缺氧血與充氧血混合後打出去,送到肺部與送到全身的含氧量一樣
HyperviscositySaturation 不可能 100% → 身體催促紅血球製造 → Hb 25–30 → hyperviscosity syndrome → thromboembolism
失去肺臟過濾肺是很大的過濾器;血液未經完全過濾 → 感染性心內膜炎、brain abscess 等
肺血管病變肺部壓力較低,若通道通暢則肺血流長期多於體循環 → 肺血管壁變化 → Eisenmenger syndrome

兩個先決條件(不是每個小朋友都能走 Fontan 這條路):

  1. Pulmonary vascular resistance 要夠低——因為肺循環將靠靜脈壓與重力驅動。臨床上可見已建立單心室循環的小朋友一旦感冒併發肺炎,PVR 上升 → SVC/IVC 回流受阻 → 頭部腫、下肢浮腫
  2. Systemic ventricle function 要夠好——把循環想成一條高速公路,心室是中途的推進站;推不出去,後面整條就塞車,上下腔靜脈回流也跟著塞住,循環很容易 collapse

為什麼僅存的心室要拿去接體循環?因為體循環的阻力/壓力較大,而肺循環阻力大約只有體循環的 1/6 至 1/5——幫浦當然要用在阻力大的那一側。

Visual｜左圖:一顆心室連出兩條粗管分別通往肺與全身,心室上標「負擔 ×2」,血液顏色是混合的紫色。右圖:目標狀態——心室只接體循環(紅),肺循環改由靜脈壓驅動的細藍箭頭自行流動。兩圖之間放兩把鑰匙,分別刻「低 PVR」與「好的心室功能」。

⭐ 考試重點｜兩個先決條件、肺循環阻力約為體循環的 1/6–1/5、以及不處理的併發症清單(hyperviscosity、栓塞、感染、Eisenmenger)。

Recall Check｜一位已完成 Fontan 的孩子因肺炎住院,家屬發現他臉腫、腳也腫。請用本課的先決條件解釋這個現象的生理機轉。

Lesson 7-5｜Fontan 三階段與那個逃生孔

TL;DR｜第一階段先平衡肺血流與體血流;第二階段(3–6 個月)SVC 接 PA;第三階段(多在 2–5 歲)IVC 接 PA,完成 Fontan。血氧目標由 80% 一路走到 95–100%。

Hook

Fontan 手術會刻意留一個 fenestration(逃生孔)——在人工血管與右心房之間挖一個洞。就像高速公路塞死時,給車子一個匝道可以下來。

Framework

為什麼要分三階段?因為剛出生時肺才剛張開,肺阻力仍然偏高,幾個月後才會下降。若一出生就把上下腔靜脈接到肺動脈,血根本回不去。

Structured Detail｜三個階段

階段時機做法目標 saturationQp/Qs
第一階段出生時平衡肺血流與體血流:肺血流不足(PA 狹窄、厲害 cyanosis)→ systemic-pulmonary shunt(BT shunt);肺血流過多、體循環不足(heart failure)→ PA banding> 80%約 2 : 1
第二階段3–6 個月,PVR 降至正常水準後SVC 接到 PA(Glenn)。好處有二:①心室減壓——部分血液不再經過心室 ②讓身體開始習慣「上腔靜脈直接回到肺動脈」的循環。同時可能將原本心臟到肺的通道縮小或綁掉(各醫師做法不同)約 80%約 0.5 : 1
第三階段多在 2–5 歲(有時 1 歲)IVC 以人工血管接到 PA,完成 Fontan circulation95–100%1 : 1

第一階段的兩種失衡:

  • 肺血流太多 → 體循環血流太少 → heart failure:發育不好、吃不下、會喘、體重減輕
  • 肺血流太少(PA 狹窄)→ 氧氣交換不足 → 厲害的 cyanosis

Fenestration(逃生孔):在連接 IVC 與 PA 的人工血管與右心房之間挖一個洞相連。一旦 PVR 上升、前方過不去,血液還有地方可逃。若長期觀察後認為不需要,可用 device closure 關閉;若一直沒有血液流過,也常會自行閉合。

歷史註記:較早年代分期沒有這麼多,對能活到一兩歲以上的病人,曾直接把 RA 接到 PA 一次完成。現今標準做法是分階段的 SVC → PA、再 IVC → PA。

Visual｜三格漫畫。①新生兒:心臟旁一條 BT shunt 或一圈 PA band,血氧計顯示 80%。②3–6 個月:SVC 一條線直接接上 PA,血氧仍 80%。③2–5 歲:IVC 也以人工血管接上 PA,血氧跳到 97%;人工血管側壁畫一個小洞連向右心房,標「fenestration」。

⭐ 考試重點｜三階段的時機、做法、目標 saturation 與 Qp/Qs 這張表,是本模組最完整的表格題;fenestration 的用途也常單獨命題。

Recall Check｜第二階段完成後,病人的血氧只靠 SVC 回流的血液做氧氣交換,卻仍能維持 80% 以上。請解釋為何 Qp/Qs 降到約 0.5:1 時,血氧不會同步崩落。
