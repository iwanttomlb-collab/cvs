Module 4｜主動脈剝離

Module 1 的那位 56 歲病人,他的診斷就在這裡。這個模組把「為什麼會剝離、怎麼分類、怎麼診斷、怎麼治療」補齊。

Lesson 4-1｜一層內膜破了以後

TL;DR｜Intima 出現 primary tear → 血液進入 media → 把 intima+media 與 adventitia 撕開 → 形成 true lumen 與 false lumen,並可能沿血流向遠端或逆行擴展。

Hook

CT 上分辨真假腔有個實用線索:false lumen 的一側牆是部分的 adventitia、另一側是內膜瓣;而 true lumen 常保有完整三層的血管壁。

Framework

先把整段主動脈的分段記熟,因為分類與治療都靠它:

分段範圍
Aortic root由 aortic annulus / aortic valve 起,經 sinotubular junction
Ascending aorta至 innominate artery 之前
Aortic archInnominate artery 至 left subclavian artery
Descending aortaLeft subclavian artery 以下至 diaphragm
Abdominal aortaDiaphragm 以下,含 suprarenal(很短)與 infrarenal
末端兩側 common iliac artery

整段主動脈的任何位置都可能發生 dissection。

Structured Detail｜病生理四步

  1. Intima 出現 primary tear;成因多為 medial degeneration,最常見 cystic medial necrosis
  2. 血流經 intimal tear 進入 media
  3. Intima + media 與 adventicia 被撕開,形成 true lumen 與 false lumen
  4. 沿血流 propagation:向遠端(distal)或逆行(retrograde dissection)

Visual｜血管壁三層剖面圖(intima / media / adventitia)。第一格:內膜出現裂口。第二格:一道血流箭頭鑽入 media。第三格:管腔一分為二,標示 true lumen(三層完整)與 false lumen(外側僅 adventitia)。第四格:兩支箭頭分別往遠端與近端延伸。

⭐ 考試重點｜「cystic medial necrosis 為最常見的 medial degeneration」與「CT 上真假腔的辨識依據」是本課核心。

Recall Check｜某病人的 primary tear 位於 descending aorta,但剝離逆行延伸到了 ascending aorta。請說明這種現象叫什麼,以及它為何會改變治療決策(提示:見 Lesson 4-2 的分類)。

Lesson 4-2｜DeBakey 與 Stanford:為什麼要兩套分類

TL;DR｜DeBakey 依解剖範圍分 I/II/III;Stanford 只問一件事——有沒有侵犯 ascending aorta。因為那一個問題就決定了「要不要立刻開胸」。

Hook

Stanford 分類看似粗糙,卻是最實用的:A 型 = 你必須做好立刻開胸置換的心理準備;B 型 = 原則上可以先做藥物治療。

Framework

DeBakey 本人是外科醫師,是最早做 aortic repair 的心血管外科名家之一,他的分類從外科手術觀點出發;Stanford 較晚出現,是從治療決策出發。

Structured Detail

DeBakey範圍Stanford原則治療
Type IAscending aorta 一路到兩側 common iliac arteryType AImmediate open grafting
Type II侷限於 ascending aorta
Type III僅 descending aorta
IIIa:較短,至 diaphragm
IIIb:一路到兩側 common iliac		Type BUncomplicated 可先 medical treatment

Visual｜四張主動脈簡圖並排,病灶以粗線標示:①全長 ②僅升主動脈 ③僅降主動脈至橫膈 ④降主動脈至兩側髂動脈。上方用一條大括號把①②框成「A」,把③④框成「B」,括號旁分別寫「開胸」與「先降壓」。

⭐ 考試重點｜Stanford A = DeBakey I + II;Stanford B = DeBakey III。這組對應關係幾乎必考。

Recall Check｜為什麼 Stanford 分類只用「ascending aorta 有無侵犯」這一個變數,就足以驅動急診端的處置決策?請用兩型的治療原則差異來說明。

Lesson 4-3｜誰會剝離:老人與年輕人的兩張清單

TL;DR｜發生率約每 10 萬人年 2–10 位,好發 60–80 歲男性。老人的頭號危險因子是高血壓;年輕人則要想 connective tissue disease 與家族史。

Hook

年輕人有一個越來越被重視的危險因子:舉重。短時間內提起重物時,血管壁承受的瞬間壓力差極大,產生 dissection 的機會相對增加。

Framework

依 IRAD(國際性主動脈剝離登錄)資料:男性較多,平均年齡 60 幾歲;女性若發生,通常年齡更大。年齡本身就把危險因子分成兩張清單。

Structured Detail

老年病人年輕病人
主要因子Hypertension(最常見)Connective tissue disease、家族史 → 本質是 genetic factor
其他AtherosclerosisWeight lifting、發炎性疾病

Genetic mutation 對照:

基因疾病
FBN1Marfan syndrome
COL3A1Ehlers-Danlos syndrome
TGFBR1 / TGFBR2Loeys-Dietz syndrome
MYH11(myosin heavy chain)近年較常見的變異

共通機轉(概略):這些 mutation 影響 extracellular matrix 或細胞內 myosin → MMP production 增加 → proteolysis → aneurysm 或 dissection。

其他值得記的危險因子:

  • Takayasu arteritis、giant cell arteritis 等發炎性疾病
  • Coarctation:狹窄近端壓力較高
  • Bicuspid aortic valve:胚胎期與 ascending aorta / root 一同發育,代表主動脈本身可能也有先天病變(呼應 Module 2)
  • 既有 aneurysm、familial thoracic aortic syndrome
  • Trauma、fluoroquinolone 使用、近年亦有 VEGF 相關警訊、吸食毒品

Visual｜一條年齡軸(20 → 80 歲)。左端聚集一堆標籤:Marfan、Ehlers-Danlos、Loeys-Dietz、家族史、舉重;右端聚集另一堆:高血壓、atherosclerosis。中央跨越全段的橫條寫「bicuspid AV / coarctation / 藥物 / trauma」。

⭐ 考試重點|「基因—疾病」四組對照(FBN1/COL3A1/TGFBR1-2/MYH11)與「bicuspid aortic valve 與升主動脈同源」是高機率考點。

Recall Check｜一位 28 歲男性、身高很高、無高血壓病史,因胸背劇痛就醫。除了立刻安排影像,病史上你還要追問哪兩類資訊?各對應本課的哪個危險因子?

Lesson 4-4｜急性胸痛:只要記住三件事

TL;DR｜典型表現是突發、銳利、撕裂樣的疼痛,八九成病人問得出來。急性胸痛的鑑別診斷,先 rule out 死亡率最高的三個:ACS、aortic dissection、pulmonary embolism。

Hook

約 5% 的 aortic dissection 會以 acute MI 表現——當 flap 侵犯到 coronary artery 造成無灌流時。所以看到 ST elevation 就直覺排除 dissection,是有風險的。

Framework

臨床 assessment 分四層:risk factor → clinical presentation → physical finding → end-organ malperfusion 的表現。最後一項最容易被忽略,卻是 dissection 特有的。

Structured Detail｜表現與對應機轉

表現機轉
突發撕裂樣胸背痛Intimal tear 與剝離延伸
Pulse deficit(carotid / brachial / femoral)Malperfusion syndrome
New onset heart murmurAcute aortic insufficiency:false lumen 擴大壓迫 true lumen → 造成 sinotubular junction / aortic valve distortion → 急性逆流
Neurological deficit侵犯 vertebral / carotid artery;Horner syndrome 很少見

Acute MI(約 5%)Flap 侵犯 coronary artery

三大致命胸痛鑑別:acute coronary syndrome、acute aortic dissection、pulmonary embolism。
Tension pneumothorax 的臨床表現與呼吸音差異明顯,通常不難分辨;pericardial tamponade 除 trauma 外,多半正是來自 aortic dissection。

Visual｜中央一個「Acute Chest Pain」的圓,向外拉出三條粗箭頭到 ACS、Aortic Dissection、PE 三個方框,三個框都用紅框標「mortality 最高」。ACS 與 Dissection 之間再畫一條雙向虛線,標「5% 重疊」。

⭐ 考試重點｜「三大致命胸痛」與「5% dissection 以 acute MI 表現」是急診情境題的標準陷阱與解法。

Recall Check｜病人有典型撕裂樣胸痛,心電圖呈現 ST elevation。為什麼此時「直接送導管室」可能是危險的決定?你會先做什麼檢查?

Lesson 4-5｜Malperfusion:動態的與靜態的

TL;DR｜Dynamic obstruction 隨心動週期「一下有一下沒有」,因為 flap 會隨壓力擺動;static obstruction 是血栓或死巷造成的完全阻塞,整個週期都沒有灌流,症狀更嚴重。

Hook

同樣是「內臟缺血」,一種是時有時無,另一種是從頭到尾都沒有——後者的 ischemia 症狀會厲害得多。

Framework

兩者的差別在於「阻塞的東西會不會動」。

Structured Detail

DynamicStatic
機轉Systolic phase 時 false lumen 壓力高於 true lumen,flap 被推去遮住分支開口;diastolic phase 壓力降低,true lumen 回復原形,血流恢復Dissection flap 侵犯分支血管造成 thrombosis / 完全 occlusion;或 false lumen 只有入口沒有出口,成為無血流的死腔
灌流時序隨 cardiac cycle 時有時無Systolic / diastolic 皆無灌流
症狀相對間歇Ischemia 症狀非常厲害

症狀嚴重度也取決於被影響的是哪一個器官。

Visual｜兩排各兩格的小動畫格。上排(dynamic):收縮期 flap 蓋住分支開口(打叉)、舒張期彈開(打勾)。下排(static):兩格都被血栓塞死(皆打叉)。

⭐ 考試重點｜dynamic vs static 的機轉區分,以及「static 症狀更嚴重」的推論,是這一段最常入題的概念。

Recall Check｜為什麼 dynamic obstruction 的血流恢復多半發生在 diastolic phase?從 true lumen 與 false lumen 的壓力關係說明。

Lesson 4-6｜診斷工具:為什麼答案幾乎總是 CT

TL;DR｜CT scan 是首選——最快、sensitivity 近乎 100%。EKG 與 biomarker 主要用來排除別的病,CXR 用於鑑別診斷,TEE 準但侵入性高,MRI 太慢。

Hook

Aortic dissection 若在急診沒被診斷出來,常常伴隨 medico-legal issue。這也是為什麼講者反覆強調急性胸痛的三項鑑別。

Framework

把工具依「用途」而非「準確度」分類:有些是為了排除別的疾病,有些是為了確定診斷。

Structured Detail

工具角色要點
EKG排除 AMI約 1/3 正常、1/3 non-specific ST-T change;注意 5% dissection 以 acute MI 表現
Biomarker輔助,價值有限D-dimer、fibrin degradation product、elastin degradation product、troponin、TGF-β,sensitivity 與 specificity 均不佳
Chest X-ray鑑別診斷對 dissection 本身敏感度與特異度都不好,但能明確看出 tension pneumothorax
CT scan確定診斷首選最快、sensitivity 幾乎 100%
Transthoracic echo床邊可用只能看到 ascending aorta,看不到 descending;肥胖病人 window 不佳;IMH 難以分辨
Transesophageal echo準確Ascending、descending 甚至 arch 都看得到,但侵入性高、急診不易取得
MRI非 first line耗時過久

CT 影像判讀:Type A 可在 ascending aorta 內見到 intimal flap(axial 與 sagittal view 皆可);Type B 則 ascending 乾淨,僅 descending 有 flap。

Visual｜一張分兩欄的工具箱圖。左欄「用來排除別的病」放 EKG、CXR、biomarker;右欄「用來確定診斷」放 CT(放最大、加星號)、TEE、TTE、MRI(依可用性由大到小排列)。

⭐ 考試重點｜「CT 為 first priority、sensitivity 近 100%」與「EKG 有 1/3 正常」是最常見的兩個數字題。

Recall Check｜一位血行動力不穩、無法離開急救室的病人疑似 type A dissection。此時 CT 不可行,你會選擇哪一項床邊工具?它的最大限制是什麼?

Lesson 4-7｜治療:A 型開胸,B 型先降壓

TL;DR｜Type A → open grafting,死亡率每小時增加 1%。Type B uncomplicated → medical therapy;complicated → TEVAR 優先於開放手術。所有病人 anti-impulse therapy 都要 on board。

Hook

Type A 的時間成本可以直接換算:每小時 +1% → 24 小時約四分之一、48 小時約一半。即使開了刀,perioperative mortality 仍約 20%;但只要撐過手術,long-term survival 相對不錯,約可達 70%。

Framework

治療決策只有兩個問題:有沒有侵犯 ascending aorta?有沒有 complication?

Complicated dissection 的定義:

  • Rupture(pericardial effusion / cardiac tamponade)
  • Malperfusion
  • 較次要者:refractory hypertension、acute diameter expansion

Structured Detail｜治療對照

型別狀態治療
Type A—Open surgical grafting(目前仍為標準;stent graft 證據等級尚不足)
Type BComplicatedTEVAR 或 open repair;越來越多證據支持 TEVAR 優先(病人 condition 通常很 critical)
Type BUncomplicatedMedical therapy always on board
Type BUncomplicated 但 high risk可考慮 early TEVAR

Anti-impulse therapy(A、B 型皆需,連等待手術期間也要):

順位藥物目的
第一線Beta blocker(IV:esmolol、labetalol;labetalol 兼具部分 alpha 與 beta 作用)不只降血壓,更要降低 LV contraction velocity → 減少主動脈 shearing stress → 降低 dissection propagation 風險
第二線Direct vasodilator(nicardipine、nitroprusside)Beta blocker 後血壓仍降不下來時使用
併行Pain control病人多有劇痛

實務細節:量血壓要用讀數較高的那隻手——較低的那一側可能根本是 malperfusion 造成的。

TEVAR 的原理:從血管內置入 stent graft,將 primary tear 覆蓋 → false lumen 逐漸 thrombosis → 達到 aortic remodeling,定義為 true lumen expansion + false lumen regression,同時改善 malperfusion。相對於傳統開放手術(需處理 visceral artery segment 的 anastomosis,極為 traumatic)侵襲性低很多。

長期追蹤:手術通常只處理其中一段,其餘仍是 residual dissection → anti-impulse therapy 需長期持續 → 年輕病人要回頭找 genetic defect → 需 serial imaging 追蹤 aneurysm formation。

Visual｜一張決策樹:根節點「Ascending 有無侵犯?」→ 有 → 「Open grafting(時鐘圖示,標 1%/hr)」;無 → 「有無 complication?」→ 有 → TEVAR;無 → 「Medical therapy」,旁邊掛一個虛線分支「high risk → early TEVAR」。整棵樹底部橫貫一條色帶寫「Anti-impulse therapy always on board」。

⭐ 考試重點｜1%/hour、24h 25%、48h 50%、perioperative mortality 20%、long-term survival 70%;以及 anti-impulse therapy「beta blocker 優先於 vasodilator」的順序與理由。

Recall Check｜為什麼 aortic dissection 的降壓不能只用 vasodilator,而必須以 beta blocker 為第一線?請用 shearing stress 與 dissection propagation 解釋,並說明單用 vasodilator 可能帶來什麼反效果。
