Module 9｜術後併發症與重症照顧

回到 Module 1 開場的那位 56 歲病人。這個模組按時間順序走過術後可能發生的每一件事,最後回到他的結局。

Lesson 9-1｜術後併發症的全景圖

TL;DR｜心臟外科術後的併發症幾乎涵蓋所有內科重症。但併發症多,不代表不該開刀——代表術後照顧與術前評估同等重要。

Hook

美國統計最常見的冠狀動脈繞道手術後,光是腎衰竭就有 3%。而這只是一長串清單的第一項。

Framework

講者的核心提問:併發症這麼多,是不是就不要開刀?當然不是。所以三件事變得關鍵——術前怎麼評估、術中怎麼避免、術後怎麼照顧。

Structured Detail｜CABG 術後常見併發症(美國統計)

併發症發生率
腎衰竭3%
輕微腸胃道出血、輕微急性腎損傷約 3%
腸胃道併發症2.5%
Reopen for bleeding2.3%
中風或昏迷2%
Sternal wound infection1.4%
術中心肌梗塞1.1%

ICU 現場:一位護理師往往要同時照顧多台機器——洗腎機、ECMO、呼吸器、IABP、monitor、多台幫浦,有時還有暫時性 pacemaker。這是心臟外科加護病房非常常見的景象。

Visual｜一張以床為中心的俯視圖,四周圍繞六台機器,各以引線標出名稱與該機器對應的併發症風險(如洗腎機↔腎衰竭、呼吸器↔ARDS)。

⭐ 考試重點｜這張發生率表適合整體記憶「量級」:腎衰竭最高(3%)、中風約 2%、sternal wound infection 約 1.4%、MODS 最低(0.6%)。

Recall Check｜面對一位擔心併發症而猶豫是否開刀的家屬,請用本課的架構(併發症多 ≠ 不該開刀)組織一段回答,並指出三個可以降低風險的介入時機。

Lesson 9-2｜術後出血:為什麼體外循環會讓人流血

TL;DR｜長時間體外循環會造成 coagulopathy(heparin、凝血因子與血小板消耗、fibrinolysis 活化),加上低體溫、血壓升高與縫合處出血。藥物與輸血控制不住時,越早 re-open 越好。

Hook

一個關鍵觀念:早點 re-open 並不會增加 sternal wound infection 的機率,反而可以避免發生 cardiac tamponade 與休克。

Framework

術後出血的來源分兩類:

  • Coagulopathy:與較長的體外循環有關——需使用 heparin;體外循環會消耗血小板與凝血因子;也會活化 fibrinolysis pathway
  • 機械性因素:手術過程中的低體溫、血壓升高、縫合處出血

Structured Detail｜處理階梯

層次做法
Heparin 造成以 protamine reverse
凝血因子/血小板缺乏輸血:FFP、platelet、cryoprecipitate
血庫無血品時高濃度凝血製劑:factor VIIa、prothrombin complex 等複合式製劑
促進凝血功能的藥物DDAVP、tranexamic acid、aprotinin
以上無效越早 re-open 越好(不增加傷口感染率,可避免 tamponade 與休克)

Visual｜一個五階的下降樓梯,每階寫一種處置(protamine → 輸血 → 凝血製劑 → 促凝藥物 → re-open),樓梯旁一個計時器,箭頭提示「越往下走越該加快」。

⭐ 考試重點｜體外循環造成 coagulopathy 的三個機轉(heparin、消耗、fibrinolysis 活化),以及「早期 re-open 不增加感染率」這個反直覺結論。

Recall Check｜住院醫師擔心「再開一次會增加傷口感染」而猶豫。請用本課的證據回應他,並說明拖延可能導致的兩個後果。

Lesson 9-3｜Cardiac tamponade:四個數字的組合

TL;DR｜心臟被擠壓 → CVP 高、血壓低、cardiac output 低、尿量少、ScvO₂ 低。這組合成一個非常辨識度高的數字圖形。

Hook

Tamponade 是心臟外科術後第一個必須排除的診斷。任何低心輸出量的病人,床邊心臟超音波先做,是 tamponade 就趕快 re-open。

Framework

機轉只有一句話:心臟受到擠壓。由此推出所有數字:

  • 心臟受擠壓 → 無法充填 → cardiac output 下降 → 血壓低、尿量少
  • 回流受阻 → CVP 上升
  • 組織攝氧增加 → ScvO₂ 下降

Structured Detail｜對照:低血容性休克的分級

創傷外科常用的出血分級(以全身血容量 5 公升計):

級數失血比例心跳血壓Pulse pressure
I< 15%大致無變化無變化無變化
II15–30%上升無變化—
III30–40%上升下降—
IV約 40% 以上異常增加降低變窄

處置:輕微出血可先補生理食鹽水;真正大量出血則要考慮輸血。

關鍵鑑別點:tamponade 的 CVP 上升,低血容性休克的 CVP 下降——同樣是血壓低、尿量少,這個數字把兩者分開。

Visual｜兩張並排的儀表板。左(tamponade):CVP 指針指向高、BP 低、CO 低、ScvO₂ 低。右(hypovolemia):CVP 指針指向低,其餘同樣偏低。兩張圖中 CVP 那一格用紅框圈起,標「唯一分歧點」。

⭐ 考試重點｜「CVP 高 + 血壓低 + CO 低 + 尿量少 + ScvO₂ 低」是 tamponade 的標準組合題;出血分級 I–IV 的心跳/血壓/pulse pressure 變化順序亦常考。

Recall Check｜術後病人血壓 82/50、尿量極少。若 CVP 是 18,與 CVP 是 3,你的診斷與下一步處置分別是什麼?

Lesson 9-4｜Low cardiac output:先排除,再用藥

TL;DR｜第一件事永遠是床邊心臟超音波排除 tamponade。不是 tamponade 才進入藥物或機械輔助:調心跳、調心律、補 preload、給強心劑、必要時降 afterload。

Hook

Low cardiac output 的皮膚表現很有辨識度:mottled skin——皮膚上出現發紫的斑紋,講者形容「很像屍斑」。

Framework

臨床表現:心跳增加、血壓下降、沒有尿、病人焦慮、冒汗、四肢冰冷,甚至 mottled skin。

處置的固定順序:

  1. 床邊心臟超音波 → 是 tamponade → 立刻 re-open
  2. 不是 tamponade → 心臟功能表現不好 → 藥物治療或機械輔助

Structured Detail｜怎麼增加心輸出量

切入點做法
Heart rate增加心跳、控制心律不整
Preload給予 volume expansion
Contractility強心劑:dobutamine、norepinephrine、dopamine、milrinone 等
Afterload術後初期的心臟若無法應付過高的 afterload,反而造成 low cardiac output → 給予 vasodilator 如 NTG
藥物無效考慮 mechanical support(見 Module 8)

用藥實務:不同強心劑在不同劑量範圍有不同的治療 target 與效果——有些較會拉血壓,有些較會增加心跳;學名與商品名要盡量能夠結合,並且要會計算劑量、會下醫囑、會泡藥。

Visual｜一個決策流程圖:起點「Low cardiac output」→ 菱形「床邊 echo:tamponade?」→「是」通向紅色框「立刻 re-open」;「否」通向一個四格方陣(HR / preload / contractility / afterload),方陣下方再接「仍無效 → 機械輔助」。

⭐ 考試重點｜「第一步必須先排除 tamponade」的順序不可顛倒;以及增加心輸出量的四個切入點。強心劑的種類與劑量範圍是講者特別點名的自學重點。

Recall Check｜為什麼術後初期給 vasodilator 反而可能增加心輸出量?請用「剛手術完的心臟無法應付過高 afterload」這個前提說明。

Lesson 9-5｜術後中風:早期與晚期是兩個故事

TL;DR｜術後中風發生率約 1–2%。早期是麻醉退了就沒醒,多與術中主動脈操作、血行動力不穩有關,典型呈 watershed infarct;晚期是醒來後第二天突然半邊無力,多與術後 AF 或小 emboli 有關。

Hook

Porcelain aorta——像陶瓷一樣鈣化的主動脈。X 光或影像上白白的一片鈣化,手術中任何一次擠壓、切開,甚至換瓣膜,都可能讓斑塊掉下來造成腦中風。

Framework

早期中風晚期中風
臨床情境麻醉藥退了就發現中風,或未完全清醒醒來後能正常對話,可能第二天突然面癱、半身無力
時機手術過程中造成恢復期發生
機轉術中對鈣化血管壁的操作 → 小血栓;術中血行動力不穩;既有頸動脈狹窄術後小 emboli;術後 AF;心臟內小血栓飄出
特徵常見 watershed infarct:術中血壓低,腦部硬化血管末梢出現循環不良與梗塞局部神經學缺損

Structured Detail｜風險來源

  • 主動脈鈣化(porcelain aorta):任何擠壓、切開、換瓣皆可能使斑塊脫落
  • 主動脈瓣鈣化:換瓣手術中的去鈣化過程,小碎屑掉落即可能造成栓塞症狀
  • 既有 carotid artery stenosis
  • 術中血壓過低

Visual｜時間軸從「手術中」到「術後第 2–3 天」。左端標「早期:沒醒 / watershed」,配一張腦部分水嶺區域上色的示意;右端標「晚期:醒後突發 / embolic」,配一個侷限性梗塞點。時間軸上方掛一顆鈣化的主動脈,兩條虛線分別指向左右兩端。

⭐ 考試重點｜早期 vs 晚期中風的時序、機轉與影像特徵對照,以及 porcelain aorta 這個名詞。

Recall Check｜一位病人術後第一天已能正常對話,第二天早上突然右側肢體無力。依本課分類,這屬於哪一型?你會優先檢查哪一項心律問題?

Lesson 9-6｜心律不整:最常見的 vs 最致命的

TL;DR｜最常見的是 AF(約 30%),相對良性;最嚴重的是 VT——發生率不高,但臺大資料顯示死亡率約 17%。

Hook

VT 最容易發生在哪一群人?心肌梗塞後接受繞道手術的病人。臺大的發生率約 2.3%,但一旦發生,死亡率約 17%。

Framework

Atrial fibrillationVentricular tachycardia
發生率約 30%約 2.3%(臺大)
嚴重度相對良性死亡率約 17%
血行動力影響多造成血壓偏低可致命
好發族群—AMI 後接受 CABG 者

Structured Detail

AF:

  • 機轉:心臟手術切開心包膜後造成的心包膜發炎;reperfusion stress
  • 預防:beta blocker;或採後側心包膜切開,均可降低 AF 發生

VT:

  • 危險因子:心臟功能較差、最近有心肌梗塞、心電圖上 Q 波較多
  • 治療:藥物如 lidocaine、amiodarone;若仍不行則需考慮電擊
  • ICD 的實務限制:健保規定需在 CABG 後三個月才可植入,這是臨床上比較困難的地方

Visual｜一張 2×2 的四象限圖,橫軸「發生率」、縱軸「致命性」。AF 落在右下(高頻率、低致命),VT 落在左上(低頻率、高致命),兩者各自標註預防與治療手段。

⭐ 考試重點｜AF 約 30%、VT 約 2.3% 但死亡率 17%;AF 的兩個預防手段(beta blocker、後側心包膜切開)是常見填空題。

Recall Check｜為什麼心臟手術本身就會誘發 AF?請說明與心包膜相關的機轉,並據此解釋為何「後側心包膜切開」可以降低發生率。

Lesson 9-7｜拔管與感染:術後的兩道關卡

TL;DR｜脫離呼吸器有明確條件清單;拔管後也還沒結束——術後感染發生率約 1–8%,死亡率很高,其中最嚴重的是中隔腔感染(mediastinitis)。

Hook

最嚴重的 sternal wound infection 可能致命;有時骨髓炎必須把整個骨頭都挖掉才能得到良好控制。而若病人胸腔內有人工血管,感染一旦波及,整段都可能得拆掉——這正是 Module 1 那位病人第 10 天時外科醫師最怕的事。

Framework

脫離呼吸器的條件:

  • 意識清楚
  • 力氣正常,四肢 muscle power 恢復
  • 咳嗽反應正常
  • 血行動力學穩定、沒有 arrhythmia
  • 不需要 re-open
  • 呼吸道暢通

達到穩定的 weaning parameter 之後才可拔管。

Structured Detail｜感染

項目內容
發生率約 1–8%,死亡率高
最嚴重Surgical site infection 中的中隔腔感染;骨髓炎有時需徹底清除骨頭
較輕微Chest tube 相關感染、pneumonia、UTI 等
危險因子術中無菌技術、手術時間長、糖尿病、肥胖、雙側內乳動脈取用、長期使用呼吸器

Visual｜一道有六個插銷的閘門,每個插銷刻上一項 weaning 條件,全部拔起後閘門才打開。閘門後方畫一條路,路上還有一個標示牌寫「感染 1–8%」。

⭐ 考試重點｜脫離呼吸器的六項條件、感染率 1–8%、以及 sternal wound infection 的危險因子清單。

Recall Check｜為什麼「不需要 re-open」也被列為拔管條件之一?請從後續麻醉與手術安排的角度說明。

Lesson 9-8｜回到那位病人:多災多難的 15 天

TL;DR｜同一位病人在一次住院中連續經歷了 type A dissection 手術 → MRSA 中隔腔感染 → 敗血性栓塞造成肢端壞死 → 復健中急性肺栓塞、PEA、CPR 56 分鐘 → 再次開胸取栓。而他最後走著回家。

Hook

第 15 天下午 2 點 20 分,護理師發現病人 consciousness change:脈搏 87、呼吸 30、血壓 42/30、SpO₂ 測不到、節律為 PEA。而就在那天早上,他還坐起來看電視、自行做呼吸訓練,看起來一副準備要拔管的樣子。

Framework

這個案例的教學價值在於:心臟外科的病人不是通過一關就沒事,而是要一關一關過。

Structured Detail｜時間軸

時間事件

術後 8 小時後躁動、踢床 → 調整鎮靜藥物;RSS 評估
第 10 天突然發燒,手腳出現紫斑(型態近似 infective endocarditis 的周邊表現);胸腔引流管顏色改變 → 培養出 MRSA → 嚴重中隔腔感染。因胸腔內有人工血管,一旦感染波及後果嚴重
第 12 天前後紫斑處末梢循環變差,出現皮下壞死與水泡;召開家庭會議,預告可能需要截肢以控制感染
第 15 天上午抗生素與胸腔引流後趨穩:GCS E3VTM6、管路引流順暢、傷口外觀乾淨、左後胸置 pigtail、使用 PGE-1(改善末梢循環)與 dopamine、四肢皆可測得脈搏、可坐起看電視與自行呼吸訓練
第 15 天 14:20Consciousness change、BP 42/30、SpO₂ 測不到、PEA → CPR、通知 ECMO team、決定放置 VA ECMO
急救 56 分鐘後ROSC:脈搏 137、BP 96/59、SpO₂ 74、心電圖為 normal sinus rhythm → 停止急救
急救後緊急 CT:升主動脈人工血管無明顯問題,降主動脈仍有殘存剝離;但右肺動脈可見明顯的 contrast filling defect → 急性肺栓塞(復健過程中腳部血栓脫落)

結局手黑了、腳黑了,但經過努力復健,仍可以走路回家

臨床提醒:CPR 之後最重要的事情是找原因——所以立刻安排了緊急電腦斷層,才找到肺栓塞這個真正的元兇。

Visual｜一條橫向時間軸(第 0 天到出院),上方標出四個尖峰事件:手術、第 10 天感染、第 15 天 PEA、再次開胸。每個尖峰之間畫一段緩慢回升的曲線,曲線末端向上收尾,標「走路回家」。

⭐ 考試重點｜這個案例把整套課程串起來:dissection(M4)→ ICU 數字(M1)→ 感染(M9-7)→ ECMO 待命(M8)→ 肺栓塞。適合作為整合型申論題的素材。

Recall Check｜病人在 CPR、ROSC 之後,為什麼「立刻安排 CT」比「先穩定血壓再說」更關鍵?請結合本案最終診斷說明,若沒有找到這個原因會發生什麼。
